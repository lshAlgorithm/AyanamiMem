# File Format

Every node — leaf or condensed — is a `.md` file with this structure:

```
---
<YAML frontmatter>
---

<body>

## Children        ← condensed nodes only
- [label](./relative/path.md)

## Related         ← optional cross-links
- [label](../other-subtree/_summary.md)
```

---

## Frontmatter fields

### Common (leaf and condensed)

| Field | Type | Description |
|---|---|---|
| `key` | `string` | 5–15 word descriptive phrase. Generated by LLM for condensed; extracted from first line for leaves. Used for embedding and search. |
| `depth` | `int` | `0` = leaf (verbatim conversation). `1+` = condensed summary. Higher = more abstract. |
| `node_kind` | `"leaf"` or `"condensed"` | Type of node. |
| `session_id` | `string` | Which session created this node. |
| `source` | `string` | Provenance: `"conversation"`, `"manual"`, etc. |
| `tags` | `[string]` | Semantic tags. For condensed, generated by LLM. |
| `earliest_at` | `ISO 8601` | Timestamp of earliest source message in this subtree. |
| `latest_at` | `ISO 8601` | Timestamp of most recent source message in this subtree. |
| `token_count` | `int` | Estimated token count of this node's body (chars ÷ 4). |
| `descendant_count` | `int` | Total leaf count reachable below (`1` for leaves). |
| `stale` | `bool` | `true` when a child has been updated and this summary needs regeneration. |

### Condensed nodes additionally

| Field | Type | Description |
|---|---|---|
| `ref_count` | `int` | Number of sessions that have a symlink to this subtree (for sharing). |
| `shared_session_ids` | `[string]` | Sessions granted access (planned, not yet implemented). |

## Edge sections

### `## Children`

Only in `_summary.md` files. Links to the direct children of this directory:

```markdown
## Children
- [Planning phase](./01-planning/_summary.md)
- [Restaurant recommendations](./02-restaurants/_summary.md)
```

For a leaf-containing directory, children are individual `.md` files:

```markdown
## Children
- [001-destinations](./001-destinations.md)
- [002-budget](./002-budget.md)
```

### `## Related`

Cross-links to other subtrees. Written by the compactor when it detects related topics in different branches, or by the user manually.

```markdown
## Related
- [Work ML project](../02-work-project/_summary.md)
```

### `## Sequence`

For leaves that are part of a conversation thread that spans directories, this section links to the previous/next leaf:

```markdown
## Sequence
- Next: [003-temples](../02-temples/003-temples.md)
```

### `## Shared`

For cross-session shared subtrees (planned, not yet implemented):

```markdown
## Shared
- [Alice's research](../../alice-session/01-research/_summary.md)
```

## Naming conventions

### Leaf files

`NNN-slug.md` where `NNN` is a zero-padded 3-digit sequence number within the directory:

```
001-i-m-planning-a-trip-to-japan.md
002-budget-is-3000-usd.md
003-kyoto-temples-recommendation.md
```

### Summary files

Always named `_summary.md`. The underscore prefix marks it as a special file (excluded from sequence numbering and `list_children`).

### Subdirectories

`NN-slug/` where `NN` is a zero-padded 2-digit sequence number:

```
01-planning-details/
02-restaurant-recommendations/
03-transportation/
```

### Special directories

`_fresh/` — staging area for uncompacted leaves. Never appears in the tree. Always included verbatim in context.

`_shared/` — symlinks to shared subtrees from other sessions (planned).

## Full example

**`04-japan-cherry-blossom-trip/_summary.md`**

```markdown
---
key: Japan cherry blossom trip planning
depth: 2
node_kind: condensed
session_id: session-abc
source: conversation
tags:
- travel
- japan
- kyoto
- cherry-blossom
earliest_at: '2026-03-20T10:00:00'
latest_at: '2026-03-23T15:12:00'
token_count: 180
descendant_count: 8
stale: false
---

The user is planning a 2-week trip to Japan in April to experience
cherry blossom season. Peak viewing is late March to mid-April, with
Tokyo blooming first and Kyoto about a week later. Key recommendations:
14-day JR Pass (50,000 yen), Fushimi Inari and Kinkaku-ji in Kyoto,
onsen experience, daily food budget 3,000–5,000 yen.

## Children
- [Planning details](./01-planning-details/_summary.md)
- [Kyoto temples](./02-kyoto-temples/_summary.md)
- [Food and restaurants](./03-food-restaurants/_summary.md)

## Related
- [Home renovation project](../05-home-renovation/_summary.md)
```

**`04-japan-cherry-blossom-trip/01-planning-details/001-i-m-planning-a-trip.md`** (leaf)

```markdown
---
key: I'm planning a 2-week trip to Japan in April. Best time for cherry blossoms?
depth: 0
node_kind: leaf
session_id: session-abc
source: conversation
tags: []
earliest_at: '2026-03-20T10:00:00'
latest_at: '2026-03-20T10:01:30'
token_count: 63
descendant_count: 1
stale: false
---

User: I'm planning a 2-week trip to Japan in April. Best time for
cherry blossoms?
